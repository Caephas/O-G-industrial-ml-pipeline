# ADR 0003: Repository License

- Status: Accepted
- Date: 2026-09-03

## Context

This repository is a public portfolio project. It must be licensed so
recruiters and reviewers can run and reuse it without ambiguity.

## Decision

The repository is MIT-licensed. The NASA C-MAPSS dataset remains subject to its
own public-data terms (NASA Open Data; the PCoE Zenodo mirror is CC-BY-4.0),
and dataset attribution lives in the README rather than in the license.

## Consequences

- Reuse is unrestricted for anyone cloning the repo.
- No code from the prior proprietary workplace project is included, so the
  license does not conflict with employer IP.
